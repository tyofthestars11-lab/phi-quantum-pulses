SECTION 1: FUNDAMENTAL PHI CONSTANTS
================================================================================

DERIVATION: Golden Ratio from quadratic equation x^2 - x - 1 = 0
  Using quadratic formula: x = (1 + sqrt(5)) / 2

  phi (Golden Ratio) = (1 + sqrt(5)) / 2
  phi = (1 + 2.2360679774997898) / 2
  phi = 1.6180339887498949

DERIVATION: phi^2 = phi + 1 (fundamental identity)
  phi^2 = 1.6180339887498949^2 = 2.6180339887498949
  phi+1 = 1.6180339887498949 + 1 = 2.6180339887498949
  Verification: phi^2 - (phi+1) = 0.00e+00 (numerical zero)

DERIVATION: 1/phi = phi - 1 (reciprocal identity)
  1/phi = 1/1.6180339887498949 = 0.6180339887498948
  phi-1 = 1.6180339887498949 - 1 = 0.6180339887498949
  Verification: 1/phi - (phi-1) = -1.11e-16 (numerical zero)

ADDITIONAL PHI IDENTITIES:
  phi^3 = phi^2 + phi = 4.2360679774997898
  phi^4 = phi^3 + phi^2 = 6.8541019662496856
  phi^5 = phi^4 + phi^3 = 11.0901699437494763
  phi^(-2) = 1/phi^2 = 1 - 1/phi = 0.3819660112501052
  phi^(-3) = 1/phi^3 = 0.2360679774997897
  2*phi - 1 = sqrt(5) = 2.2360679774997898
  Verification: sqrt(5) = 2.2360679774997898

================================================================================

DERIVATION: Tetrahedral angle = arccos(-1/3)

SECTION 5: GOLDEN SPIRAL r(theta) = a * phi^(theta/pi)
================================================================================

DEFINITION: r(theta) = a * phi^(theta/pi)
  where phi = 1.6180339887498949
  a = initial radius (scale factor, set to 1.0)

DERIVATION:
  The golden spiral is a logarithmic spiral where the growth
  factor is related to phi. For every pi radians (180 deg) of
  rotation, the radius multiplies by phi.

  r(theta) = a * phi^(theta/pi)
  r(0) = a * phi^0 = a * 1 = a
  r(pi) = a * phi^1 = a * 1.6180339887498949
  r(2*pi) = a * phi^2 = a * 2.6180339887498949
  r(3*pi) = a * phi^3 = a * 4.2360679774997898
  r(4*pi) = a * phi^4 = a * 6.8541019662496856

================================================================================
SECTION 7: SPIRAL-BASED COORDINATE TRANSFORMATIONS
          FOR SCROLL FIBER MAPPING
================================================================================

SCROLL GEOMETRY: The papyrus scroll is modeled as a golden spiral
in polar coordinates, unwinding from center outward.

TRANSFORMATION 1: Polar Golden Spiral to Cartesian
  r(theta) = a * phi^(theta/pi)
  x(theta) = r(theta) * cos(theta) = a * phi^(theta/pi) * cos(theta)
  y(theta) = r(theta) * sin(theta) = a * phi^(theta/pi) * sin(theta)

TRANSFORMATION 2: Arc length along golden spiral
  ds = sqrt(r^2 + (dr/dtheta)^2) * d_theta

  dr/dtheta = a * phi^(theta/pi) * ln(phi) / pi
  ln(phi) = 0.4812118250596035
  ln(phi)/pi = 0.1531744812650166

  Let k = ln(phi)/pi = 0.1531744812650166
  Then r(theta) = a * e^(k*theta)
  dr/dtheta = a * k * e^(k*theta) = k * r(theta)

  ds/dtheta = r * sqrt(1 + k^2)
            = r * sqrt(1 + 0.0234624217108069)
            = r * 1.0116631957874156
